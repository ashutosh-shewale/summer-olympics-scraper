# Benchmark: populating the database

Generated by `python -m olympics benchmark` on 2026-11-25.

## Set-up

- **Workload:** scrape and parse 14 Summer Olympics Wikipedia pages (1968–2020) and write them to SQLite.
  The index page is fetched once beforehand and is not timed.
- **Repeats:** 3 runs per configuration, interleaved round-robin; the table reports the median.
- **Speed-up:** `(t_sequential - t) / t_sequential`, i.e. the share of wall-clock time saved.
- **Machine:** Windows-10-10.0.26200-SP0, 16 logical CPUs, Python 3.11.9.
- **Network:** live requests to en.wikipedia.org over the benchmarking machine's connection; absolute times vary with the network,
  so compare configurations within one report, not across reports.
